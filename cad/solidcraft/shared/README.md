# Shared (non-production)

Parts reused across prototypes and mockups, **not** in the final keyboard.

| Part | File | Used in | Notes |
|------|------|---------|-------|
| membrane | `membrane.json` | single-key prototype, ergonomics mockup | From donor membrane keyboard; dome + trace film as return / contact stand-in |
| keycup-cylinder | `keycup-cylinder.json` | single-key prototype, ergonomics mockup | Simple cylindrical keycap for fit and travel tests; not a production cap |
| key-stack | `key-stack.json` | single-key prototype, ergonomics mockup | Optional subassembly: membrane + keycup-cylinder with joints; insert when the same stack is reused as a unit |

Production parts belong under `parts/` and `assemblies/`, not here.
