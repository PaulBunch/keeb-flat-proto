# SolidCraft models

Parametric 3D source files for this project.

- **Format:** SolidCraft plain JSON (full feature history)
- **Open with:** [SolidCraft](https://github.com/tangency-labs/solidcraft)
- **Not** a universal CAD interchange format (unlike DXF/STEP)

```bash
# open a model
solidcraft cad/solidcraft/mockups/case-left.json
```

Export STEP/STL/3MF locally when needed; do not commit those exports.
